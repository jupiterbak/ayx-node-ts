Description

The Workflow Management API provides a means for managing workflows in Alteryx Server.

This client extends the V1 client and implements the V3 API endpoints, providing comprehensive workflow management capabilities including:

  • Retrieving workflow details and listings
  • Creating and updating workflows
  • Managing workflow versions
  • Downloading workflow packages
  • Retrieving workflow questions and jobs
  • Deleting workflows

Permanently deletes a workflow from Alteryx Server.

This method removes a workflow and all its versions from the server. This is a destructive operation that cannot be undone, so it should be used with caution.

If the workflow is associated with schedules, the operation will fail by default. Setting the force parameter to true will delete all associated schedules before deleting the workflow.

Common use cases include:

  • Removing obsolete or unused workflows
  • Cleaning up test workflows
  • Removing workflows that have been migrated to other systems
